# Student Information System - Flask

A web application that retrieves student information using Flask and SQLite.

## Features
- Displays student ID, name, department, and marks.
- Uses Flask for the web application.
- Uses SQLite to store student records.

## Run
1. Activate the virtual environment.
2. Install dependencies: pip install -r requirements.txt
3. Run: python app.py
4. Open http://127.0.0.1:5000
